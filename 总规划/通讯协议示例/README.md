# 初版完整报文示例

先阅读[职责与命令](../希康智能_上下位机通讯协议与状态机_V0.1.md)，再看[完整报文附录](../希康智能_初版完整报文示例.md)和[验收标准](../希康智能_初版通讯与主功能验收标准.md)。

完整场景目录包含每个场景的请求、回复和全字段状态；[场景索引](完整场景/场景索引.json)列明前置条件和预期结果。根目录原有8份JSON保留作快捷样例；完整覆盖以“完整场景”为准。

全部报文无请求、方案或穴位ID。每个文件是一条消息；数字前缀仅是文件排序。场景必须分别准备前置条件，不可把目录全部顺序发送。所有温度、力、距离及穴位位置均为模拟联调用例，尚未通过实机验证。

当前共63个完整场景，191条完整JSON消息，另有1条故意损坏的原始文本。
