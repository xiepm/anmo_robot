# 希康智能通讯协议示例

配套设计：[上下位机通讯协议与状态机](../希康智能_上下位机通讯协议与状态机_V0.1.md)。

这些文件用于开发讨论和模拟器联调。设备ID、定位、令牌与策略均为演示占位，不是可直接下发实机的配置。

| 文件 | 用法 |
|---|---|
| 01_启动请求.json | UI到下位机的完整命令信封 |
| 02_接收回执.json | 已受理，不代表动作完成 |
| 03_启动完成事件.json | 已进入运行，不代表整次服务结束 |
| 04_艾灸计划_仅演示.json | 嵌入plan.validate的payload.plan；三穴各600000ms |
| 05_按摩力度字段_仅演示.json | 按摩点的intensity对象，不是完整方案 |
| 06_参数调整载荷.json | session.update_parameters的payload，不是完整命令信封 |
| 07_状态快照_仅演示.json | 下位机到UI的状态和测量有效性示例 |

所有JSON已通过语法解析；艾灸总时长与分穴时长、快照进度已核对。尚未执行真实控制柜通讯、运动、温控或力控验证。
