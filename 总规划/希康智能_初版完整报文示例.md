# 希康智能初版完整报文示例

适用协议：[同机通讯与状态机](希康智能_上下位机通讯协议与状态机_V0.1.md)。本附录只展开现有5个命令，不增加功能或ID字段。所有JSON均为完整消息，没有省略号。文件名中的顺序数字只用于查阅，不进入报文。

每个场景单独设置前置条件，不能把整个目录依次发送给设备。`上→下`可作为请求发送，`下→上`由模拟下位机产生，不能反向发送。合法GET_STATUS直接返回STATUS；其他命令返回REPLY。非法格式请求统一返回失败REPLY，包括非法GET_STATUS。已受理后的执行失败通过STATUS表达。

所有样例使用模拟器。背部名称沿用界面，上肢/下肢名称参考[本地穴位代码](../zhenjiu/acupoint_locator_refactored.py)，仅用作通讯标签，不证明视觉精度或可执行性。模拟点的几何位置由工装夹具配置。温度47、力15、间隙30仅为格式测试值，不是人体使用建议。

相机采用机械臂末端随动安装后，所有成功SCAN场景增加前提：已由现场调试将机械臂置于合适观察位并停稳，采集图像与实际法兰位姿可配对。SCAN不自动移动机械臂；模拟器用对应有效输入完成测试。

## 阅读顺序

先看查询、三个部位扫描、六种部位/能量方案、开始、完整运行、停止，再看失败场景。定时STATUS与查询返回使用相同结构；运动期间未展示的每200ms刷新也必须包含全部字段。

## 模拟器测试配置

仅为可重复的软件测试，模拟器允许温度40至50、力1至20、间隙10至100，分别使用协议中的C、N、mm单位；正例47/15/30通过，反例999或负间隙拒绝。模拟反馈最大有效年龄500ms、正常停止反馈延迟100ms、停止阶段超时2秒、扫描超时30秒。以上是模拟夹具配置，不得作为实机或人体服务默认参数。测试脚本可注入反馈，但生产UI不开放模拟注入命令。

## 状态取值补充

未选择能量类型时actual_energy的type、value、unit均为null且valid=false；选择类型但无有效测量时保留type/unit，仅value为null。ERROR下remaining_time_s冻结在故障前剩余值，只供说明；不是可恢复方案。任务已清除并回IDLE后remaining_time_s为0。跨点TRANSFER的current_point表示即将接近的目标穴位。

## 格式错误规则

能解析cmd时REPLY回显cmd；不能解析时cmd为null。未知命令、字段缺失、错误类型、非法枚举及不允许的多余字段拒绝。GET_STATUS、START、STOP的data必须为空对象。重复的“名称＋侧别”在初版方案中拒绝。状态外请求先拒绝，不能清除正在执行的方案。

## 01 查询空闲状态

前置条件：下位机已启动，尚未定位。

通过表现：GET_STATUS直接返回完整STATUS，没有额外REPLY。

上→下 · 上位机请求

```json
{
  "cmd": "GET_STATUS",
  "data": {}
}
```

下→上 · 下位机返回/上报

```json
{
  "type": "STATUS",
  "data": {
    "mode": "SIMULATION",
    "robot_connected": true,
    "robot_feedback_valid": true,
    "state": "IDLE",
    "step": "NONE",
    "region": null,
    "positioning_valid": false,
    "available_points": [],
    "current_point": null,
    "remaining_time_s": 0,
    "actual_energy": {
      "type": null,
      "value": null,
      "unit": null,
      "valid": false
    },
    "actual_gap_mm": null,
    "gap_valid": false,
    "result": "NONE",
    "error": ""
  }
}
```

## 62 查询请求格式错误

  }
}

}
