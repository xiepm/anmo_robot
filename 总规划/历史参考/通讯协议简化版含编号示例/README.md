# 初版通讯报文示例

配套文档：[功能验证版通讯与状态机](../希康智能_上下位机通讯协议与状态机_V0.1.md)。

只需先验证：确认参数 → 开始 → 状态反馈 → 停止。

| 文件 | 作用 |
|---|---|
| 01_查询状态.json | GET_STATUS请求，也用于UI存活检查 |
| 02_确认参数_模拟示例.json | SET_PLAN完整请求，3个点共60秒 |
| 03_开始.json | START请求，使用确认参数返回的plan_id |
| 04_停止.json | STOP请求，取消后续动作 |
| 05_确认参数回复.json | 参数保存成功及每点时间 |
| 06_状态反馈_模拟示例.json | 状态、剩余时间与反馈数值 |

能量、距离及点ID仅供模拟报文说明，不是可直接下发的实机参数。模拟/实机模式由下位机配置，不能由请求切换。SCAN留到视觉接入阶段实现。

JSON语法和示例时间已核对；尚未做实机通讯或运动验证。
